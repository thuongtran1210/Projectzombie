# Enemy spawn warnings (Defense3D)

The runtime owns DefenseSpawnWarningTimeline and exposes IDefenseSpawnWarningSource to the presenter. The UI observes immutable snapshots and never enqueues, delays or consumes jobs. Scheduled notices are seeded from the same compiled plan and authored placement used by the run. The planner closes them only after actual spawn success, expiry or overflow.

Presentation: five-second upcoming countdown by default; red pulsing pending badge while due but blocked; green arrival confirmation for 0.8 gameplay seconds after actual spawn. The arrival confirmation also covers the time-zero wave without moving its spawn time. Pause freezes gameplay time and hides views; resume recomputes from the same clock. Restart restores authored points, resets scheduled states and removes dynamic flights.

Ghost Cannons announce a Quasi Du / quaidu landing when they launch, using ballistic + parachute duration and the target landing anchor. This announcement does not enqueue an enemy. The existing touchdown code still enqueues the landing job. Its warning remains pending if placement/capacity/factory blocks it. Cancelling a flight closes its warning. Destroying a cannon retains an existing flight according to the original gameplay rule; it only stops new launches. Runtime entry points reject stale run generations.

Badge symbols: Ma Giap = armored shield, Ma Giap commander = crowned shield, Yaksha = boss crown; fish, bat, elite, parachute and cannon symbols are retained. Unknown types use the generic demon. A cannon symbol alone does not add a new cannon spawn schedule. Bosses are allocated slots first, followed by elite/live landings and ordinary enemies. The authored canvas still has 32 noninteractive slots; dense overdue queues may exceed this and lower-priority badges can be omitted. This change does not add crowd-count aggregation.

Menu: Tools > ProjectZombie > Validate Spawn Warnings. Outputs: scratch/SpawnWarningValidation.txt and .xml, scratch/EnemySpawnWarningsPreview.png. Preview columns: armored, commander, boss, fish, bat, elite, parachute, cannon, generic demon. Rows: upcoming, pending, arrived. The synchronous NUnit fixtures cover warning state, planner outcomes and stage configuration; the isolated badge render does not prove full-match placement or device performance. Stage schedules, damage, safe distance, capacity and frame spawn budgets are unchanged.
